# Avatar App

A React-based web application that uses an external API to generate AI-powered avatars. The project demonstrates API integration, HTTP requests using Axios, and building a user-facing application with React.

## Live Demo

[View Avatar App](https://avatar-app-ps593.netlify.app/)

## Overview

Avatar App provides a web interface for generating and viewing avatars through an external service. It was developed using React and Axios to handle communication with the API.

The project focuses on integrating an external API into a React application and presenting the resulting avatar through a simple user interface.

## Tech Stack

- **Frontend:** React.js
- **Programming Language:** JavaScript
- **HTTP Client:** Axios
- **Styling:** CSS
- **Development Environment:** Create React App

## Key Concepts Demonstrated

- Building reusable components with React
- Integrating external APIs
- Making HTTP requests using Axios
- Managing frontend application structure
- Styling a web interface using CSS

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/pragati-singh-593/avatar-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd avatar-app
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open your browser and visit:

   ```text
   http://localhost:3000
   ```
